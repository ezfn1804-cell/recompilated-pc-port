# NEON RIFT · OVERDRIVE 2.0.0

Jeu de survie en **3D**, rapide, avec dash offensif, combos **×5**, bonus **+2 projectiles**, trois vaisseaux, améliorations et boss.

## Télécharger et jouer

**[Télécharger le jeu Windows (.exe)](https://github.com/ezfn1804-cell/recompilated-pc-port/raw/refs/heads/downloads/neon-rift-overdrive-2.0.0/Neon-Rift-Overdrive-2.0.0-Windows-x64.exe)**

Windows 10 / 11 **64 bits**, environ 100 Mo. Téléchargez le fichier puis lancez-le par double-clic. Aucun serveur, compte ou installation de Node.js nécessaire. Le jeu fonctionne hors ligne.

- **ZQSD / WASD / flèches** : déplacement.
- **Espace / clic droit** : dash offensif.
- **Clic gauche maintenu** : visée libre ; sinon tir automatique.
- **E** : surcharge quand la jauge atteint 100 %.
- **Échap** : pause, **F11** : plein écran, **M** : son.

L’exécutable de développement est **non signé**. Il a été compilé depuis Linux ; son lancement natif Windows reste à vérifier sur un PC Windows.

Cette branche contient les fichiers de téléchargement ; elle ne modifie pas la branche `main`.
